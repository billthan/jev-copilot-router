# Benchmarks

The benchmark package measures both skill routing and full-tool-catalog risk classification. Both live runners report agreement, reliability, stability, latency, token use, and OpenRouter-reported cost.

## Provider Policy

The default method is Jev only. Normal Copilot model work is not routed through OpenRouter.

VS Code does not expose GitHub Copilot's internal skill-routing call as a benchmark endpoint. The optional `llm` method is therefore a controlled OpenRouter emulation and is blocked unless the caller explicitly supplies `-AllowOpenRouterLlmBaseline`.

## Offline Self-Test

```powershell
& "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" `
  -NoProfile -ExecutionPolicy Bypass `
  -File ".\benchmark\self-test.ps1"
```

## Jev-Only Run

```powershell
& ".\benchmark\benchmark.ps1" `
  -WorkspacePath "C:\path\to\workspace" `
  -Methods jev `
  -Repeats 3 `
  -FailOnApiError
```

## Explicit Historical A/B Reproduction

```powershell
& ".\benchmark\benchmark.ps1" `
  -WorkspacePath "C:\path\to\workspace" `
  -Methods jev,llm `
  -LlmModel "openai/gpt-5.6-sol" `
  -LlmReasoningEffort none `
  -AllowOpenRouterLlmBaseline `
  -Repeats 3 `
  -FailOnApiError
```

This explicit A/B mode is for benchmark reproduction only. It is not used by either installed hook.

Add representative prompts to `cases.json`. Use an empty `expected` array when no skill should load and multiple names for multi-skill cases.

## Full Tool Catalog

The generated tool catalog combines the installed Copilot `toolEmbeddings.json` registry with `tool-catalog-supplement.json`, which captures core and deferred tools exposed to the agent but absent from that registry. The current corpus contains 268 unique tools, exactly one coverage case per tool, and five reviewed deny controls.

Regenerate and validate the inputs whenever VS Code, Copilot, extensions, or MCP servers change:

```powershell
& ".\benchmark\Export-ToolCatalog.ps1"
& ".\benchmark\New-ToolBenchmarkCases.ps1"
& ".\benchmark\tool-benchmark-self-test.ps1"
```

Run the complete Jev benchmark with three repeats:

```powershell
& ".\benchmark\tool-benchmark.ps1" `
  -Repeats 3 `
  -FailOnApiError
```

The runner rejects duplicate, missing, mismatched, or unknown tool coverage before making live calls. Every request carries the full catalog, even in a filtered smoke run. A credit preflight also stops the run before model calls when the OpenRouter balance is exhausted.

Catalog allow/ask labels are generated by a conservative action-token policy and measure agreement with that policy, not objective safety. The production hook blocks only high-confidence deny outcomes and otherwise defers to the active VS Code permission mode.

The sanitized three-repeat result is available in [results/2026-09-23-full-tool-catalog.md](results/2026-09-23-full-tool-catalog.md): 100% catalog coverage, 100% reliability, 92.4% policy agreement, 99.3% stability, 404.63 ms mean latency, and `$0.56484187` total cost across 819 decisions.
