# Initial Benchmark

Date: 2026-09-23

Configuration:

- 24 reviewed cases
- 3 repeats
- 144 completed API calls
- Jev `typesafe/jev-1.13`, threshold `0.72`
- Explicit test-only LLM baseline `openai/gpt-5.6-sol`
- Alternated call order
- No API errors
- Total measured cost: `$0.035678684`

On this seed corpus, the LLM baseline led exact match by 4.1 percentage points. Jev was approximately 4.9 times faster and 5.9 times cheaper, and it performed better on no-skill controls.

Most mismatches involved overlapping `project-setup-info-local` and `project-setup-info-context7` descriptions. Jev also selected both `agent-customization` and `troubleshoot` for one skill-loading diagnosis where the reviewed label expected only `troubleshoot`. The LLM baseline falsely selected `get-search-view-results` for a normal workspace text search.

The LLM comparator was an explicit benchmark-only OpenRouter call. Production routing sends only Jev decisions to OpenRouter; all normal model work remains on GitHub Copilot credits.
